# Release notes

## Portfolio showcase edition — 2026-08-05

This edition prepares the JobHunt MU codebase for professional GitHub review. It adds repository governance, CI and security automation, architecture and database diagrams, installation and deployment guidance, explainable-AI documentation, synthetic sample data, and a public-showcase checklist.

### Privacy change

All uploaded resumes, runtime media, local database artifacts, editor workspaces, and bulk scraped datasets were removed from the showcase package. Existing local project folders should still be checked manually before any Git push.

### Upgrade impact

No schema migration or product feature was introduced by this documentation edition. Review repository placeholders and run the full local test suite before publishing.
