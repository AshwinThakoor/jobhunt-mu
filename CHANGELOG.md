# Changelog

All notable changes are documented here. This project follows [Semantic Versioning](https://semver.org/) and a Keep a Changelog structure.

## [Unreleased]

### Added
- Complete open-source documentation suite.
- Mermaid architecture and database diagrams.
- GitHub Actions CI, community health files, Docker configuration, Ruff, and pre-commit.
- Synthetic sample dataset and screenshot capture plan.

### Security
- Removed user-uploaded resumes, generated media, database artifacts, and bulk scraped data from the public showcase package.

- Application Studio with grounded resume, cover-letter, and application-email drafts.

### Added
- Import-run history, freshness tracking, stale-job management, and improved skill normalization.

## [0.2.0] - 2026-07-30

### Added
- Expanded MyJob.mu pagination and Basic/Premium recommendation separation.

## [0.1.0] - 2026-07-30

### Added
- Resume extraction, explainable matching, recommendations, saved jobs, and candidate dashboard.
